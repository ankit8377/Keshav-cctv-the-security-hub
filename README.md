# Keshav-cctv-the-security-hub
CP Plus [मॉडल नंबर ] सीसीटीवी कैमरा आपके घर, दुकान और ऑफिस की सुरक्षा के लिए एक बेहतरीन विकल्प है। यह कैमरा उच्च गुणवत्ता वाली वीडियो रिकॉर्डिंग, नाइट विज़न और स्मार्ट मोशन अलर्ट्स के साथ आता है। इस े CP Plus के मोबाइल ऐप (gCMOB / ezyKam+) के ज़रिए कही ं से भी आसानी से एक्सेस किया जा सकता है।
